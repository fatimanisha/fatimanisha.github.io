Property Management System

Developed a Java-based Property Management System allowing realtors to manage properties and users to view available listings. The system features a GUI built with Java Swing and follows the MVC architecture for maintainable and modular design.

Project information

  • Category: Backend
  • Project date: March, 2023
  • Technologies: Java, Java Swing, JDBC, MySQL, MVC Architecture, DAO Pattern, File I/O, Java Logging API, Git
  • Source Code: Property-Management-System

Overview

  • Implemented role-based access: Realtors can add, delete, and manage properties; Users can browse and search listings.
  • Included detailed property attributes such as facilities, owner details, number of tenants, and price.
  • Built a GUI using Java Swing for intuitive interaction and CLI fallback for versatility.
  • Persisted property data to files and implemented comprehensive error handling with logging.
  • Structured the project following MVC architecture with modular packages for models, controllers, and views.
